# 旅の貼り帳（TravelCollage）

旅の写真やチケットを、生成りの台紙に一枚ずつ貼っていくデジタルのトラベルコラージュ帳です。
紙を手で貼るときの「ペタッ」という感覚を、アニメーションごと画面に持ちこむことを目指しています。

## できること

### 台紙をつくる
- **写真を貼る**：複数枚まとめて選べます。台紙へのドラッグ&ドロップにも対応し、iPhone の HEIC 写真も読み込めます。フチは「白フチ・ちぎり・そのまま」から選べます。
- **写真を読み取って組み立てる**：手帳のページを撮った写真を貼ると、Claude がページの中身を読み取り、デジタルで組み立て直します。
  - 貼ってある紙（チケット・地図・絵はがき・写真・スケッチなど）は、1枚ずつ輪郭に沿って切り抜きます。破った紙は「ちぎり」、切った紙は「はさみ」のフチになります。
  - 手書きの文字は読み取って、手書き風の書体で書き直します。マスキングテープは柄と向きを合わせて引き直し、うずまきの飾りやスタンプも置き直します。
  - 元のページと同じ配置・同じ重なり順で、下の紙から一枚ずつ貼られていきます。
  - 普通の風景写真は、白フチとテープをつけた1枚の写真として貼ります。
  - 読み取りには Anthropic の API キーが必要です（下の「写真の読み取りを有効にする」を参照）。キーがない場合は、写真の色と模様から紙片を探す簡易版の切り抜きになります。
- **テープをひく**：台紙をなぞった方向と長さでマスキングテープが引けます。柄はドット・ストライプ・クラフト・ミント・ギンガム・透明の6種類です。
- **文字を書く**：手書き・マーカー・明朝・タイプの4書体と、赤青二色重ねの文字を使えます。
- **シール・スタンプ**：丸シール、日付スタンプ、消印、うずまき線、搭乗券があります。
- 貼ったものはドラッグで移動、ハンドルで回転と拡大縮小ができます。前面・背面の入れ替え、複製、削除もできます。
- **貼る様子を再生**：紙が落ちてきて貼られ、テープが引かれ、文字が書かれていく様子を最初から再生します。
- 台紙を PNG 画像として書き出せます（Claude 上で開いたときのみ）。

### 旅を整理する
- **旅を追加**：写真をドロップすると、写真の位置情報（EXIF の GPS）から国を、撮影日から日付を自動で入れます。
- **地図**：訪れた国が塗られ、旅した場所にページのサムネイルがピンで立ちます。近くの旅はまとまって枚数バッジがつき、タップすると拡大されます。
- **地域別・国別のカテゴリ**：東アジア、東南アジア、南アジア、中央アジア・コーカサス、中東、ヨーロッパ、アフリカ、北米、中南米、オセアニアで絞り込めます。地域を選ぶと国でも絞り込めます。
- **一覧**：地域、国の順に旅をアルバムのように並べて表示します。
- **本で見る**：旅のページを1冊の本に綴じて、3D のページめくりで見返せます。PC では見開き、スマホでは1ページずつ表示します。

## 使い方

`index.html` をブラウザで開くだけで動きます。ビルドは不要です。

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で `main` ブランチのルートを指定してください。

### 写真の読み取りを有効にする（Vercel）

写真の読み取りは `api/analyze.js`（Vercel のサーバーレス関数）から Claude API を呼び出します。

1. [Anthropic Console](https://console.anthropic.com/) で API キーを発行します。
2. Vercel のプロジェクトで Settings → Environment Variables を開き、`ANTHROPIC_API_KEY` にキーを登録します。
3. 再デプロイします。

任意の設定：
- `ALLOWED_ORIGIN`：公開している URL（例 `https://travel-collage-kappa.vercel.app`）を入れると、ほかのサイトからこの関数を呼べなくなります。API キーの使われすぎを防ぐため、設定をおすすめします。
- `ANTHROPIC_MODEL`：使うモデル。省略時は `claude-sonnet-5-5` です。

写真1枚を読み取るごとに API の利用料金がかかります。claude.ai の Artifact として開いた場合は、API キーなしで読み取れます。

## データの保存先

| 開き方 | 保存先 |
| --- | --- |
| claude.ai の Artifact として開いたとき | Artifact のデータベースと画像ストレージ。PC とスマホのどちらからでも続きを作れます |
| `index.html` を直接開いたとき、または GitHub Pages | そのブラウザの localStorage。写真は縮小して保存しますが、容量の上限（おおむね 5MB）に注意してください |

## 構成

- `index.html`：アプリ本体。HTML・CSS・JavaScript と世界地図のデータがすべて入っています。
- `api/analyze.js`：写真の読み取り用のサーバーレス関数（Vercel）。

- 台紙の描画：紙片ごとに Canvas で描画しています。画面表示と画像の書き出しで同じ描画処理を使います。
- 世界地図：Natural Earth 1:50m の国境データを簡略化して埋め込み、日本語の国名と地域の対応表をつけています。
- 外部ライブラリ（CDN から読み込み）
  - [d3](https://d3js.org/) 7.8.5：地図の投影、ズーム、国の判定
  - [topojson-client](https://github.com/topojson/topojson-client) 3.1.0
  - [exifr](https://github.com/MikeKovarik/exifr) 7.1.3：写真の位置情報と撮影日の読み取り（必要なときだけ読み込み）
  - [heic2any](https://github.com/alexcorvi/heic2any) 0.0.4：HEIC の変換（ブラウザが HEIC を表示できないときだけ読み込み）
- フォント：Google Fonts の Zen Old Mincho、Zen Kaku Gothic New、Klee One、Yusei Magic、Special Elite

## クレジット

- 地図データ：[Natural Earth](https://www.naturalearthdata.com/)（パブリックドメイン）。[world-atlas](https://github.com/topojson/world-atlas) 経由で使用しています。
- 国名の日本語表記：[i18n-iso-countries](https://github.com/michaelwittig/node-i18n-iso-countries) をもとに、一部を通称に置き換えています。
- 地域の分類：[world-countries](https://github.com/mledoze/countries) の小地域をもとにしています。イランは中東、ジョージア・アルメニア・アゼルバイジャンは中央アジア・コーカサスに入れています。
